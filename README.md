# Список задач (To-Do List)

Минималистичный список задач на чистом HTML, CSS и JavaScript — без сборки и зависимостей.

## Возможности

- **Добавление** задач (Enter или кнопка «+»).
- **Отметка выполненных** — клик по кружку слева от задачи.
- **Удаление** — кнопка «×» справа (появляется при наведении).
- **Сохранение** — задачи хранятся в `localStorage` браузера и остаются после обновления страницы или её закрытия.
- Дополнительно: фильтры «Все / Активные / Выполненные», счётчик оставшихся задач, «Очистить выполненные»,
  редактирование по клику на текст (Enter — сохранить, Esc — отмена), тёмная тема по системной настройке,
  адаптивная вёрстка и поддержка клавиатуры.

## Запуск

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html   — разметка страницы
styles.css   — оформление (светлая и тёмная темы)
app.js       — логика: добавление, отметка, удаление, хранение в localStorage
```
